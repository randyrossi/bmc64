| [BMC64 Keyboard/Joystick PCB](https://www.pcbway.com/project/shareproject/BMC64_Keyboard_Joystick_PCB.html) | The original PCB made when BMC64 started. ## How to add a Community Project

Open a pull request that adds a row to the right table with the project name linked to its homepage or documentation, a short description, and the author.

This page is for reference only and is not a place for marketing projects. Keep descriptions objective: say what the project is and does, not how good it is. Avoid marketing language and claims such as "best", "recommended", "official" or "fully compatible". Link to the project's own documentation rather than copying details here.

If you are a project's author and want your entry changed or removed, open a pull request or contact us on [Discord](https://discord.gg/yXU6huQymG).

BMC64 and its maintainers reserve the right to edit or remove any entry at any time.
